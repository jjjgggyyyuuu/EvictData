CSV Format Information
Recommended CSV Columns

For best results, your CSV file should contain the following information:

  • Case Number: Unique identifier for the eviction case
  • Tenant Name: Name of the tenant being evicted
  • Property Address: Address of the property involved
  • Filing Date: Date when the eviction was filed
  • Court Date: Scheduled court hearing date
  • Judgment Date: Date when judgment was rendered
  • Judgment Amount: Amount of the judgment
  • Writ Date: Date when writ of possession was issued
  • Status: Current status of the eviction
AI-Powered Column Mapping

Don't worry if your column names don't match exactly. Our system uses intelligent detection to:

  • Automatically identify date columns
  • Recognize monetary fields
  • Detect eviction-related information
  • Suggest the most appropriate mappings
  • Allow you to adjust mappings if needed
